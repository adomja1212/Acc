# توكتوك رالي 🛺

لعبة سباق توكتوك ثلاثية الأبعاد في شوارع القاهرة وقت المغرب، مبنية بـ Three.js في ملف واحد (`index.html`).

- ٣ حلبات: وسط البلد، كورنيش النيل (فلايك وبرج القاهرة)، وطريق الأهرام
- ٥ أنواع جو تختار منها: نهار، مغرب، ليل، مطر (طريق مبلول والمسكة أقل)، وتلج (كل حاجة بيضا والطريق بيزحلق)
- زرار خروج برسالة «هل تريد الخروج؟ نعم / لا»، وزرار الرجوع في الموبايل بيسأل نفس السؤال
- عربيات في الطريق: تاكسي، ميكروباص، ربع نقل محمّل بطيخ، وأتوبيس، وعربيات راكنة على الرصيف
- ٦ تكاتك (إنت + ٥ منافسين بذكاء اصطناعي)، والخبطة الجامدة بتعطّل اللي قدامك وتلفّه
- لعب أونلاين بين لاعبين حقيقيين بس (من ٢ لـ ٦ في السباق، من غير تكاتك كمبيوتر)، وكل اللي فاتحين اللعبة بيشوفوا بعض في قايمة «أونلاين دلوقتي»، وفيه زرار «ادخل أسرع سباق»
- جرافيك: ظلال ناعمة، Bloom، سماء غروب حقيقية، انعكاسات على الدهان، شبابيك منورة، فوانيس وزينة، نخيل، جوامع، والأهرامات في الأفق
- دريفت بيشحن النيترو، عدّاد سرعة، خريطة مصغّرة، ترتيب مباشر، أصوات موتور وكلاكس
- تحكم بالكيبورد، أو على الموبايل بالأزرار أو بإمالة الموبايل زي الدركسيون، و٣ مستويات جودة
- تكتب اسمك وبيظهر في الترتيب والنتايج ولصحابك أونلاين

## رابط عام للعب أونلاين
العبة شغالة على GitHub Pages: `https://adomja1212.github.io/Acc/`

اللعب أونلاين برا claude.ai بيتم مباشرة بين الأجهزة (WebRTC) عن طريق سيرفرات Nostr العامة، من غير حساب ولا سيرفر خاص. صاحب السباق يدوس «انسخ رابط الدعوة» ويبعته، أو صحابه يلاقوا السباق في «سباقات مفتوحة».

## تطبيق أندرويد (APK)
آخر نسخة دايمًا على الرابط ده:
`https://github.com/adomja1212/Acc/releases/latest/download/tuktuk-rally.apk`

- بيتبني تلقائي على GitHub Actions مع كل تعديل في اللعبة (`.github/workflows/android.yml`).
- اللعبة والخطوط وthree.js متجمّعين جوه التطبيق (`tools/build-www.mjs`)، فاللعب لوحدك شغال من غير نت.
- التطبيق بيشيك لوحده على GitHub أول ما يفتح، ولو فيه نسخة أحدث بيظهر «فيه تحديث جديد» بزرار «حدّث دلوقتي».
- عشان التحديث يتثبّت فوق القديم، كل النسخ لازم تتوقّع بنفس المفتاح: حطّه في GitHub كـ Secret باسم `ANDROID_DEBUG_KEYSTORE` (الملف بصيغة base64). من غيره كل نسخة بتطلع بمفتاح جديد ولازم تمسح القديمة قبل التثبيت.

## التشغيل
افتح `index.html` في المتصفح (محتاج إنترنت لتحميل Three.js والخطوط)، أو شغّل سيرفر بسيط:

```
npx serve .
```
