# نظام المحاسب — نظام ERP متكامل (واجهة ويب)

واجهة ويب احترافية باللغة العربية (RTL) لبرنامج محاسبي متكامل، بقائمة جانبية كحلية قابلة للطي حسب الإدارات.

## الإدارات والشاشات
| الإدارة | الشاشات |
|---|---|
| البيانات الأساسية | العملاء، الموردون، الأصناف، الموظفون، العمال، المخازن، الإدارات |
| الحسابات | شجرة الحسابات (4 مستويات)، القيود اليومية، القوائم المالية |
| الخزينة | الخزائن والبنوك، سندات القبض، سندات الصرف |
| المبيعات | فواتير المبيعات، عروض الأسعار، مرتجعات المبيعات |
| المشتريات | أوامر الشراء، فواتير المشتريات، مرتجعات المشتريات |
| المخازن | الأصناف، أذون الإضافة، أذون الصرف، التحويلات المخزنية |
| شئون العاملين | الموظفون، الحضور والانصراف، الرواتب، الإجازات |
| شئون العمالة | العمال، يوميات العمال، السلف والجزاءات |
| الميكنة | المعدات والآلات، تشغيل المعدات |
| الصيانة | أوامر الصيانة، الصيانة الدورية |

## المزايا
- **شجرة حسابات كاملة**: أصول، خصوم وحقوق ملكية، مصروفات، إيرادات؛ طي وتوسيع، بحث، إضافة حساب فرعي باقتراح الكود تلقائياً، تجميع الأرصدة للحسابات الرئيسية.
- **القوائم المالية**: قائمة الدخل، المركز المالي، ميزان المراجعة — محسوبة من الشجرة، مع الطباعة.
- كل الشاشات: بحث، تصفية، إضافة، تعديل، حذف، تصدير CSV، وإجماليات.
- لوحة تحكم بمؤشرات كل إدارة وتنبيهات (فواتير متأخرة، أصناف تحت حد الطلب، صيانة متأخرة).
- نسخ احتياطي واستعادة لقاعدة البيانات بصيغة JSON من صفحة الإعدادات.

## الربط بين الشاشات (الترحيل التلقائي)
كل مستند يولّد قيداً محاسبياً تلقائياً، وكل الأرصدة تُحسب من الحركات (لا تُكتب يدوياً):

| المستند | القيد |
|---|---|
| فاتورة مبيعات | من حـ/ العملاء ← إلى حـ/ المبيعات + حـ/ مصلحة الضرائب |
| مرتجع مبيعات | من حـ/ المبيعات ← إلى حـ/ العملاء |
| سند قبض | من حـ/ الخزينة ← إلى حـ/ العملاء (أو الحساب المقابل) |
| فاتورة مشتريات | من حـ/ المخزون أو المصروف ← إلى حـ/ الموردين |
| مرتجع مشتريات | من حـ/ الموردين ← إلى حـ/ المخزون |
| سند صرف | من حـ/ الموردين (أو المصروف) ← إلى حـ/ الخزينة |
| الرواتب | من حـ/ الرواتب ← إلى حـ/ البنك + حـ/ التأمينات |
| يوميات العمال / المكافآت | من حـ/ أجور العمالة ← إلى حـ/ الخزينة |
| سلفة عامل | من حـ/ سلف العاملين ← إلى حـ/ الخزينة |
| أمر صيانة مكتمل | من حـ/ صيانة وقطع غيار ← إلى حـ/ الخزينة |

- **الأرصدة المحسوبة**: الحسابات (افتتاحي + حركات)، العملاء والموردون، الخزائن والبنوك (من الحساب المرتبط)، الأصناف لكل مخزن (أول المدة + إضافة − صرف ± تحويلات).
- **حالة الفاتورة** (معلقة / مدفوعة جزئياً / مدفوعة / متأخرة) تُحسب من السندات والمرتجعات المرتبطة بها.
- **حالة المعدة** تصبح "في الصيانة" عند وجود أمر صيانة مفتوح، و**حالة الصيانة الدورية** تُحسب من التاريخ.
- **كشوف**: كشف حساب لأي حساب في الشجرة (دفتر الأستاذ)، كشف حساب عميل/مورد، كارت صنف — مع رصيد متحرك وروابط للمستندات.
- **إجراءات سريعة**: تحصيل فاتورة، سداد فاتورة مورد، تحويل عرض سعر أو أمر شراء إلى فاتورة، إنشاء أمر صيانة من الخطة الدورية.
- **حماية البيانات**: منع الصرف بأكثر من رصيد المخزن، منع حذف سجل مستخدم في مستندات أخرى، تحديث الاسم في كل الشاشات عند تعديله، تنبيه عند تجاوز حد الائتمان أو رصيد الخزينة، ترقيم تلقائي للمستندات.

## قاعدة البيانات
- **سحابية مشتركة** عند فتح البرنامج من claude.ai: كل سجل مستند مستقل (`<الجدول>/<المعرف>`)، مزامنة لحظية بين كل المستخدمين والأجهزة، سعة حتى 25,000 سجل.
- **الصلاحيات** حسب مستوى المشاركة: المالك والمحرر (كل الصلاحيات + شجرة الحسابات والإعدادات وأدوات المدير)، المساهم (إدخال وتعديل)، المشاهد (مشاهدة فقط).
- كل سجل يحفظ **آخر تعديل: من وإمتى**.
- **المفضلة وتثبيت القائمة** تُحفظ لكل مستخدم.
- صفحة **قاعدة البيانات**: الجداول وعدد السجلات والسعة، ونسخ احتياطي واستعادة (JSON).
- عند فتح `index.html` محلياً بدون claude.ai يعمل في **وضع محلي** (المتصفح) ويحمّل البيانات التجريبية من `seed.js`.

## تسجيل الدخول والصلاحيات
- **أول تشغيل**: إنشاء حساب مدير النظام (في الوضع السحابي لمالك البرنامج فقط).
- **صفحة الدخول**: اسم المستخدم وكلمة المرور، "تذكرني" لمدة 30 يوماً، إظهار/إخفاء كلمة المرور، "نسيت كلمة المرور؟"، إيقاف مؤقت بعد 5 محاولات خاطئة.
- **المستخدمون والصلاحيات**: إضافة وتعديل وإيقاف وحذف المستخدمين، تعيين كلمة مرور، ومصفوفة صلاحيات لكل شاشة (عرض / إضافة / تعديل / حذف) + صلاحيات خاصة (تصدير، نسخ احتياطي، أدوات المدير، إدارة المستخدمين). قوالب جاهزة: مدير، محاسب، أمين مخزن، مندوب مبيعات، شئون عاملين، ميكنة وصيانة، مشاهد.
- كلمات المرور مشفّرة بـ PBKDF2 مع ملح عشوائي ولا تُخزَّن كنص.
- كل تعديل يُسجَّل باسم المستخدم الذي قام به.

## التشغيل
افتح `index.html` في المتصفح مباشرة — لا يحتاج خادماً. تُحفظ البيانات في `localStorage` بالمتصفح.

## الملفات
- `index.html` — الهيكل
- `styles.css` — التصميم (متجاوب مع الجوال + طباعة)
- `app.js` — طبقة قاعدة البيانات والمنطق
- `seed.js` — بيانات تجريبية للوضع المحلي فقط
