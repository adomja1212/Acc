# نظام المحاسبة — واجهة قاعدة البيانات

واجهة ويب احترافية (RTL) لقاعدة بيانات برنامج محاسبي، بقائمة جانبية باللون الكحلي.

## الصفحات
- **لوحة التحكم**: مؤشرات الإيرادات والمصروفات وصافي الربح والنقدية، رسم بياني، أحدث القيود والفواتير.
- **دليل الحسابات**، **القيود اليومية**، **الفواتير**، **العملاء**، **الموردون**، **المخزون**: جداول مع بحث وتصفية وإضافة وتعديل وحذف وتصدير CSV.
- **التقارير المالية**: قائمة الدخل، الميزانية العمومية، ميزان المراجعة (تُحسب من دليل الحسابات).
- **الإعدادات**: بيانات المنشأة والعملة وضريبة القيمة المضافة.

## التشغيل
افتح `index.html` مباشرة في المتصفح — لا يحتاج إلى خادم أو تثبيت.
تُحفظ البيانات في `localStorage` بالمتصفح، ويمكن استعادة البيانات التجريبية من صفحة الإعدادات.

## الملفات
- `index.html` — الهيكل والقائمة الجانبية
- `styles.css` — التصميم (متجاوب مع الجوال)
- `app.js` — البيانات والمنطق
